## First launch

The app isn't signed with an Apple or Microsoft certificate yet, so the system asks once.

**macOS:** open the .dmg and drag BMH Workspace into Applications. Open it; macOS says it can't verify the developer, so click *Done*. Then go to *System Settings → Privacy & Security*, scroll down, click *Open Anyway* next to BMH Workspace and confirm. After that it opens normally.

**Windows:** run the installer. If you see *Windows protected your PC*, click *More info → Run anyway*.

## Lần mở đầu tiên

Ứng dụng chưa được ký bằng chứng chỉ của Apple hay Microsoft, nên hệ điều hành sẽ hỏi một lần.

**macOS:** mở file .dmg, kéo BMH Workspace vào Applications rồi mở. macOS báo không xác minh được nhà phát triển, bấm *Xong*. Vào *Cài đặt hệ thống → Quyền riêng tư & Bảo mật*, kéo xuống, bấm *Vẫn mở* cạnh BMH Workspace và xác nhận. Từ lần sau ứng dụng mở bình thường.

**Windows:** chạy file cài đặt. Nếu thấy *Windows đã bảo vệ PC của bạn*, bấm *Thông tin thêm → Vẫn chạy*.
